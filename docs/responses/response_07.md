# 질문 07 — Security Group 최소화 기준

## 질문

보안 그룹 규칙을 어떤 기준으로 최소화했는지 허용·미허용 포트를 설명할 수 있는가?

## 답변

기준은 “서비스 제공과 관리에 지금 필요한 통신만 허용한다”이다.

- TCP 80은 Nginx HTTP 서비스를 외부에 공개해야 하므로 `0.0.0.0/0`에서 허용했다.
- TCP 22는 관리용 SSH이므로 학습자의 현재 Public IPv4 한 개만 `/32`로 허용했다.
- HTTPS 443은 이번 핵심 범위에서 TLS를 구성하지 않았으므로 열지 않았다.
- MySQL 3306, PostgreSQL 5432 등 DB 포트는 DB 자체가 없고 외부 공개할 이유도 없어 열지 않았다.
- ICMP, 임의 애플리케이션 포트, 전체 포트 범위도 허용하지 않았다.

이 방식은 공격 표면을 줄이고, 규칙을 봤을 때 각 포트의 존재 이유를 바로 설명할 수 있게
한다. 학습자 IP가 바뀌면 SSH를 전체 공개하는 대신 기존 `/32` 규칙을 새 `/32`로 교체한다.
