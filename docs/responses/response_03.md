# 질문 03 — Security Group 인바운드 검증

## 질문

보안 그룹 인바운드가 필요한 포트만 허용하며, SSH(22)가 특정 IP로 제한되어 있는가?

## 답변

`lab-cloud-web-sg`의 인바운드는 다음 두 규칙만 허용했다.

| 용도 | 프로토콜/포트 | 소스 | 이유 |
| --- | --- | --- | --- |
| 웹 서비스 | TCP 80 | `0.0.0.0/0` | 외부 사용자가 HTTP 서비스에 접근 |
| 서버 관리 | TCP 22 | 학습자 Public IPv4 `/32` | 지정된 한 IP에서만 SSH 접속 |

HTTPS, DB 포트, 전체 포트 범위는 열지 않았다. 특히 SSH 22를 `0.0.0.0/0`으로
허용하지 않았으며 `0–65535` 전체 허용 규칙도 없다. Security Group은 상태 저장 방식이므로
허용된 요청에 대한 응답 트래픽은 별도 인바운드 규칙 없이 반환된다.
